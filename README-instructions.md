# BHS Software Engineer - Technical Assessment

Welcome! This assessment contains two use cases that reflect real scenarios in airport baggage handling systems (BHS) software development.

## Instructions

1. **Choose one or both** — You may complete one use case (2-3 hours) or both (4-5 hours total). Completing both is not required but appreciated.

2. **AI tools are allowed** — You may use ChatGPT, Copilot, Claude, or any AI assistant. We're evaluating how effectively you use these tools, not whether you can code from memory.

3. **Document your approach** — For each use case, include a README explaining:
   - How you understood the problem
   - Your investigation/design process
   - Key decisions and trade-offs
   - How you would verify your solution works
   - Any assumptions you made

4. **Deliverables** — Submit a ZIP file or GitHub repository containing:
   - Your code/solution files
   - A README per use case (or one combined README)
   - Any diagrams or documentation you created

5. **Time limit** — You have 48 hours from receiving this assessment. We expect 2-4 hours of actual work.

## Use Cases

| Folder | Title | Focus |
|--------|-------|-------|
| `use-case-1-phantom-bag/` | The Phantom Bag | Debugging, root cause analysis, operational thinking |
| `use-case-2-dashboard/` | The Dashboard Request | System design, integration, trade-off reasoning |

## Evaluation Criteria

We will evaluate your submission on:

- **Problem Understanding** — Did you identify the core issue/requirements?
- **Approach** — Was your methodology systematic and logical?
- **Solution Quality** — Is your solution robust, maintainable, testable?
- **Communication** — Can you explain your work clearly?
- **Autonomy** — Did you proactively identify edge cases, risks, next steps?

## Questions?

If anything is unclear, email your recruiter. We can answer clarifying questions — asking good questions is part of the assessment!

Good luck!
